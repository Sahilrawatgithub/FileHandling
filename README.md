# File Handling in C#

## Overview
This repository contains implementations of file handling operations in C#, focusing on working with **TXT, CSV, and JSON** files. It covers reading, writing, appending, and deleting operations using built-in C# classes.

## Features
- Read and write **TXT** files
- Process **CSV** files (read/write using delimiters)
- Work with **JSON** files (serialization & deserialization)
- Error handling and validation for file operations

## Technologies Used
- **C#**
- **.NET**
- **System.IO** for file operations
- **Newtonsoft.Json** for JSON handling

## File Operations
### 1. TXT File Handling
- Read content from a text file
- Write data to a text file
- Append data to an existing text file
- Delete a text file

### 2. CSV File Handling
- Read CSV file and parse data
- Write data to a CSV file
- Append new rows to an existing CSV file
- Handle CSV formatting issues

### 3. JSON File Handling
- Convert objects to JSON and save to a file
- Read JSON file and deserialize it to objects
- Modify JSON data and update the file
